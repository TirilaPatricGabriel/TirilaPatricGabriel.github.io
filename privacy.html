Lorecut Studio privacy policy

Last updated: 17 November 2026

Lorecut Studio is a personal tool used only by its owner, on the owner's own computer.

What data it uses

  • Through Google's YouTube Data API: the owner's own channels, videos and playlists, in order to upload videos and set their details, thumbnails, captions and playlists.
  • Through the YouTube Analytics API (read-only): view counts, watch time and similar statistics for the owner's own channels and videos.

Where it is kept

Sign-in tokens are stored in the operating system's credential store on the owner's computer. Statistics are kept in local files on that computer. Nothing is sent to any server other than Google's own APIs, and no data is sold, shared or used for advertising.

Google API Services

Lorecut Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
