Lorecut Studio

Lorecut Studio is a personal desktop tool that its owner uses to publish their own videos. It runs only on the owner's computer.

With the owner's permission it uploads the owner's finished videos to their own channels, sets each video's title, description, tags, thumbnail, playlist, captions, language and publish time, and reads the channels' YouTube Analytics so the owner can see how their videos perform.

It is not offered to anyone else, and it does not access any other person's account or data.
